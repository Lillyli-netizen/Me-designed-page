03 研究项目

基于改进 Faster R-CNN 的马铃薯叶片病害识别

本科毕业论文。针对原始 Faster R-CNN 在农业病害检测场景下精度不足的问题， 以 MobileNetV4 替换传统 VGG/ResNet 骨干网络以降低计算开销， 并引入坐标注意力（Coordinate Attention）机制增强模型对病斑位置与尺寸的敏感度。 在 PlantVillage 数据集上完成训练与对比实验， 采用 mAP@0.5 作为核心评价指标，并构建了基于 Flask 的可视化推理界面用于模型部署验证。

探索性研究项目：将大语言模型集成至车辆纵向控制（VLM）框架， 利用 LLM 的自然语言理解与推理能力辅助跟车决策与异常工况识别。 涉及 Python 仿真环境搭建、VLM 模型参数调优、LLM API 调用链路设计， 以及控制稳定性与时延特性的初步分析。
